# Pandas

데이터프레임에서 특정 열을 인덱스(index_col=)로 지정하는 이유는 코드가 단순해지고, 데이터 조회 속도가 빨라지며, pandas의 강력한 고급 기능들을 사용할 수 있기 때문입니다. 

예를 들어,

Date,Close,Volume

2026-10-16,61000,12000000

2026-10-19,61500,14500000

이렇게 index_col=[0]을 사용하여 데이터 읽기

# 0번째 열인 'Date'를 행 이름(인덱스)으로 지정하며 읽어옵니다.

df = pd.read_csv("samsung_stock.csv", index_col=[0])


출력해 보면 Date가 일반 데이터 열이 아니라, 왼쪽의 **기준 축(인덱스)**으로 잡힌 것을 볼 수 있습니다.

            Close    Volume

Date                       

2026-10-16  61000  12000000

2026-10-19  61500  14500000


💡 이렇게 인덱스로 만들면 무엇이 좋을까요?

날짜를 0번째 인덱스로 지정해 두면, 다음과 같이 특정 날짜의 데이터만 직관적으로 쏙 골라낼 수 있습니다.

print(df.loc["2026-10-19"])

1. 데이터를 찾고 선택할 때 코드가 훨씬 간결해집니다.

만약 회원 ID가 user_99인 사람의 이메일을 찾고 싶다고 가정해 보겠습니다.

• 인덱스로 지정하지 않았을 때 (불편함 ❌):

조건 필터링을 거쳐야 하므로 코드가 길어집니다.

df[df['user_id'] == 'user_99']['email']


• index_col=을 사용했을 때 (편리함 ⭕):

.loc을 사용해 주소나 사전(dict) 데이터를 찾듯 직관적으로 꺼낼 수 있습니다.python

df.loc['user_99', 'email']


2. 대용량 데이터에서 조회 속도가 압도적으로 빨라집니다.

• 일반 컬럼에서 특정 값을 찾으려면 pandas는 위에서부터 아래로 데이터를 하나하나 다 훑어야 합니다 (Full Scan).

• 하지만 인덱스로 지정하면 내부적으로 책의 '색인(Index)'이나 내부적인 해시 테이블처럼 작동합니다. 데이터가 수백만 행이 있어도 df.loc['원하는값']을 입력하면 주소를 바로 찾아가기 때문에 조회 속도가 거의 즉시(O(1)) 이루어집니다.
